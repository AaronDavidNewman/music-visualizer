# Tasks: Top-Energy Notes

**Input**: Design documents from `/specs/017-top-energy-notes/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/note-count-api.md, quickstart.md

**Tests**: Included, following the plan: pytest for the choice, the spread, the pictures and the API; vitest for the new validation, texts and the rendered control. Behavior in a real browser is checked by the quickstart steps.

**Organization**: Tasks are grouped by user story. Paths are relative to the repository root. Backend commands run in `backend/` with the venv's Python (`.venv/Scripts/python -m pytest`), frontend commands in `frontend/` (run `npm` from PowerShell: the bash tool fails after it). The API field is `note_count` (whole number 12 to 84).

**Working notes** (learned in features 010 to 016): do not use `git stash`; keep each existing file's line endings (many files are CRLF, and `sed -i` can strip them) when editing from a script; write scripts with the Write tool and keep non-ASCII characters (such as `×`) out of bash commands and heredocs; no bare `cat >`; every test tone must sit on an analysis bin center; mutation-check the new tests (break the code, see them fail, restore); report honestly what was not verified (no real browser walk-through has ever been done in this project). The user wants to **see the result**, so the implementation ends with rendered frames sent to them (T017).

**Rules for the tests of this feature**: no test states a colormap name or a number of contour levels. Use `COLORMAPS`, `DEFAULT_COLORMAP`, `FIRST`, `SECOND`, `DECODABLE`, `WITHOUT_BLACK`, `INVALID` from `backend/tests/colormap_names.py`, and `near_scale` from `backend/tests/test_contour.py` where a color is compared with the colormap by position. The spread is tested against `np.interp` itself and against its defining properties; the choice against a plain-Python ranking; pictures by decoding them. Reusable helpers of `test_resolution_rendering.py` (`tile_index`, `tile_middles`, `expected_tile_colors`, `rgb`, `write`, `notes`) and of `test_resolution.py` (`with_np_interp`) may be imported.
