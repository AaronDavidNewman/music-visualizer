# Tasks: Peak Rings

**Input**: Design documents from `/specs/036-peak-rings/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/peak-rings.md](contracts/peak-rings.md), [quickstart.md](quickstart.md)

**Tests**: Tests are written first (they fail where behaviour is missing), against an independent rule written out in the test (plain Python loops, not the code under test); a mutation check follows each implementation task (`D:\\...\\scratchpad\\mutate.py` and `mutate_front.py` of the session, or the same idea by hand; `python -B`, `__pycache__` cleared). Backend commands are run in `backend/` with `.venv/Scripts/python.exe`; frontend commands in `frontend/` with `npx vitest run` and `npx vue-tsc --noEmit`; long runs go to the background. Heredocs with quotes can fail in the shell tool: put scripts in files.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies)
- **[Story]**: the user story of the spec (US1 the rings in the middle of the ring of letters, US2 they come with the type and need nothing)

## Path Conventions

Web application: `backend/app/...`, `backend/tests/...`, `frontend/src/...`.
