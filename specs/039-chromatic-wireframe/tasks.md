# Tasks: Chromatic Wireframe

**Input**: Design documents from `/specs/039-chromatic-wireframe/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/chromatic-wireframe.md](contracts/chromatic-wireframe.md), [quickstart.md](quickstart.md)

**Tests**: Tests are written first (they fail where behaviour is missing), against an independent rule written out in the test (plain Python loops); a mutation check follows each implementation task (the helpers `mutate.py` and `mutate_front.py` of the session scratchpad, `python -B`, `__pycache__` cleared). Backend commands in `backend/` with `.venv/Scripts/python.exe`; frontend in `frontend/` with `npx vitest run` and `npx vue-tsc --noEmit`; long runs in the background. Heredocs with quotes or backticks can fail in the shell tool: put scripts and long test blocks in files (Write tool), then append. **Do not edit `decay.py`, `decay_exp.py` or `chromatic_decay.py` beyond the one constant of T007, and do not touch the user's uncommitted `PRETEND_NEIGHBORS` edit** (new tests follow `chromatic_decay.circle_points`, never a hard-coded decay value).

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies)
- **[Story]**: US1 the lines (their numbers, colors and history), US2 the view (hidden lines, depth, limits, smooth drawing), US3 the type chosen and set (job, page, documentation)

## Path Conventions

Web application: `backend/app/...`, `backend/tests/...`, `frontend/src/...`.
