# Tasks: Interpolated Resolution

**Input**: Design documents from `/specs/016-interpolated-resolution/`

**Prerequisites**: plan.md, spec.md, research.md, data-model.md, contracts/resolution-api.md, quickstart.md

**Tests**: Included, following the plan: pytest for the interpolation, the writers and the API, vitest for the new validation, texts and the rendered control. Behavior in a real browser is checked by the quickstart steps.

**Organization**: Tasks are grouped by user story. Paths are relative to the repository root. Backend commands run in `backend/` with the venv's Python (`.venv/Scripts/python -m pytest`), frontend commands in `frontend/` (run `npm` from PowerShell if the bash tool fails after it). The API field is `resolution` (whole number 1 to 5).

**Working notes** (learned in features 010 to 015): do not use `git stash`; keep each existing file's line endings (many files are CRLF, and `sed -i` can strip them) when editing from a script; write scripts with the Write tool and keep non-ASCII characters (such as `×`) out of bash heredocs; no bare `cat >`; every test tone must sit on an analysis bin center; mutation-check the new tests (break the code, see them fail, restore); report honestly what was not verified (no real browser walk-through has ever been done in this project).

**Rules for the tests of this feature** (features 014 and 015): no test states a colormap name or a number of contour levels. Use `COLORMAPS`, `DEFAULT_COLORMAP`, `FIRST`, `SECOND`, `DECODABLE`, `WITHOUT_BLACK`, `INVALID` from `backend/tests/colormap_names.py`, and `near_scale` from `backend/tests/test_contour.py` where a color is compared with the colormap by position. The interpolation is tested against `np.interp` itself and against its defining properties; rendering is tested by decoding the pictures.

**Reference hashes of the 4 s test file at resolution 1** (recorded before feature 015's last change and re-checked after it; they must not change): tiles default `28e60886…d780`, blended width 15 `187ac989…2db0`, `viridis` with smoothing 0.4, window 3, threshold 3 `ae8869d0…a5ce` (full values in quickstart.md), contour default `fbf26807…ba04` (it was `282f98e5…a4dd` until the user committed a per-frame color scale for the contour on 2026-10-12, commit 49bab02).
