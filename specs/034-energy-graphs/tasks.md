# Tasks: Energy Graphs

**Input**: Design documents from `/specs/034-energy-graphs/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/energy-graphs.md](contracts/energy-graphs.md), [quickstart.md](quickstart.md)

**Tests**: Tests are written first (they fail where behaviour is missing), against an independent rule written out in the test (plain Python loops, not the code under test); a mutation check follows each implementation task (break the rule, see the test fail, restore; `python -B`, `__pycache__` cleared). Backend commands are run in `backend/` with `.venv/Scripts/python.exe`; frontend commands in `frontend/` with `npx vitest run`; long runs go to the background.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies)
- **[Story]**: the user story of the spec (US1 the histogram, US2 the harmonic pie, US3 the loudness pie, US4 the picture, the setting and the page)

## Path Conventions

Web application: `backend/app/...`, `backend/tests/...`, `frontend/src/...`.
