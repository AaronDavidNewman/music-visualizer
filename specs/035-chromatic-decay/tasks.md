# Tasks: Chromatic Decay

**Input**: Design documents from `/specs/035-chromatic-decay/`

**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/chromatic-decay.md](contracts/chromatic-decay.md), [quickstart.md](quickstart.md)

**Tests**: Tests are written first (they fail where behaviour is missing), against an independent rule written out in the test (plain Python loops, not the code under test); a mutation check follows each implementation task (break the rule, see the test fail, restore; `python -B`, `__pycache__` cleared). Backend commands are run in `backend/` with `.venv/Scripts/python.exe`; frontend commands in `frontend/` with `npx vitest run` and `npx vue-tsc --noEmit`; long runs go to the background. Heredocs with quotes can fail in the shell tool: put scripts in files.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependencies)
- **[Story]**: the user story of the spec (US1 the 12 circles charged by the loudest octave and drawn on the ring, US2 the decay to the fourth and fifth above, US3 the whole-number decay rate and the end-to-end type, US4 the page)

## Path Conventions

Web application: `backend/app/...`, `backend/tests/...`, `frontend/src/...`.
